# gamohud

Самостоятельный TUI-инструмент в стиле MangoHud. Фокус — мониторинг ресурсов в реальном времени + управление профилями.

## Идея
Сделать минималистичный оверлей-инструмент с акцентом на производительность и практичность для геймера на Linux.

## Планируемый функционал
- Мониторинг: FPS, frametime, CPU/GPU load/temp, VRAM/RAM, clock, power
- Настраиваемый оверлей (положение, шрифт, цвет, фильтры)
- Профили под игры
- Быстрый просмотр/переключение
- Минимум зависимостей, один бинарник (потом) или просто запуск

## Десктопное приложение (GUI)

Помимо TUI доступен полноценный Qt-интерфейс с оверлеем поверх окон.

Запуск из исходников:

```
./run-gui.sh
```

Вкладки:
- **Dashboard** — живые метрики (CPU, RAM, GPU, VRAM, температури, FPS)
- **Presets** — список/редактирование/применение MangoHud.conf
- **Games** — список игр (Steam/Lutris/Bottles/Heroic/manual), запуск в один клик,
  привязка пресета и профиля Game Mode
- **Overlay & Settings** — кастомизация оверлея (позиция, прозрачность, шрифт,
  цвета, набор метрик, click-through) и включение FPS-логирования MangoHud

### Оверлей поверх окон
Оверлей — безрамочное always-on-top окно Qt, показывает FPS и метрики ресурсов.
Включается кнопкой в настройках или из трея. FPS берётся из лога MangoHud
(включите «Enable MangoHud FPS logging» в настройках).

### Сборка и установка

```
./build-gui.sh     # сборка dist/gamohud-gui (PyInstaller)
./install.sh       # установка в ~/.local + .desktop ярлык
```

После установки приложение запускается из меню как **Gamohud** (без терминала).
